## Additional findings

- Some host protocol types and implementation classes are structurally reachable through exported constructors. Their presence in this audit does not endorse public exposure. Part B should distinguish the app-facing contract from browser/backend ports before changing native buffer protocols.
- The public media constructor admits an internal-view type whose backing object exposes byte methods; those structurally reachable declarations are included rather than silently omitted.
- Byte buffers used as mutable destinations cannot accept immutable NSEData without changing their purpose. Keep those explicit writable web bridges and offer NSEData results for ordinary reads.
- Numeric audio/plane arrays are values with numerical element semantics; a generic ArrayBuffer backing parameter is not by itself a reason to wrap a Float32Array in NSEData.

The full machine-readable inventory is [public-byte-signatures.json](public-byte-signatures.json).
