## Consolidated Apple deviations and limits

1. DFX replaces Dispatch. Protocols are interfaces; simple enum cases are frozen strings; option sets are opaque singleton members passed in arrays; payload/static types are classes. 3. Tier 0 uses one browser realm. Concurrent queues/concurrentPerform use a legal serial schedule. 4. QoS is cooperative browser host scheduling, not OS thread priority. PostTask/yield/MessageChannel/setTimeout availability varies. No item interruption, worker pool, worker termination, compiler conversion, Tier 2, benchmark, App Nap or adoption is included.
5. Monotonic nanoseconds use safe JavaScript numbers, approximately 104 days, with the pinned future sentinel. Wall rawValue uses bigint and Apple's unsigned negative-epoch encoding. 6. Browser timers have soft deadlines. Throttling, event-loop stalls, clock changes and host resolution can exceed leeway. Repeating phase, missed-fire coalescing, half-interval subsequent leeway, strict separation and maximum host-delay rechecks are implemented without real-time claims.
